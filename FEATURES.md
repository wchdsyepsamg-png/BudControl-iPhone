# Feature map

## Works through iOS/CoreBluetooth when exposed
- BLE discovery and connection
- GATT service/characteristic discovery
- Reads, notifications, indications
- Standard battery/device data when exposed
- RSSI and audio-route information
- Guided baseline/action/diff capture
- Candidate ranking and noise filtering
- Persistent observed-event notes
- Copyable Finder reports

## Companion UI / local preferences
- ANC / Transparency / Off interface
- EQ presets and custom EQ UI
- Hi-Res / low-latency preference UI
- Touch-control preference UI
- In-ear / auto play-pause / multipoint UI
- Find-left / find-right interface
- Theme and diagnostics

## Requires verified proprietary command mapping
- Actual ANC mode writes
- Actual proprietary EQ writes
- Hi-Res / gaming mode writes
- Gesture configuration writes
- In-ear setting writes
- Multipoint setting writes
- Earbud ringing commands

## Intentionally not automated
- Firmware flashing
- Bootloader access
- Authentication bypass
- Factory-reset command guessing
- Fuzzing unknown characteristics
